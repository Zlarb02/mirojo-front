## Configuration requise

1. Créer le fichier `.env` :
```bash
cp .env.example .env
```

2. Remplir les variables :
```ini
SUPABASE_URL="https://votre-instance.supabase.co"
SUPABASE_KEY="sb_xxxxxxxxxxxxxxxxxxxxxxxx"
```

3. Variables obligatoires :
- `SUPABASE_URL` : URL complète de votre instance Supabase
- `SUPABASE_KEY` : Clé publique d'API (ANON_KEY)
